# Home_Network
Project Overview

Designed and configured a home network using Cisco Packet Tracer, including wired and wireless devices, DHCP, IP addressing, wireless security, and connectivity testing.

Technologies & Skills
- Cisco Packet Tracer
- IPv4
- DHCP
- DNS
- Wireless networking
- WPA2/AES
- Ethernet
- Network troubleshooting
- IP configuration

Network Components
- Cable modem
- Wireless router
- Desktop PCs
- Laptop
- Smartphone
- Tablet
- Web server

Configuration
- Configured router and network devices
- Configured DHCP for client devices
- Configured wireless SSID and security
- Connected wired and wireless clients
- Verified IP addressing
- Tested network connectivity
